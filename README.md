# Иман — исламский сайт

Статический сайт без сборки. Работает на GitHub Pages.

## Что внутри

- **Коран**: все 114 сур, арабский текст (Усмани), переводы (Кулиев, Османов, Крачковский, узбекский — Содик), чтение вслух (Мишари аль-Афаси), закладки, «Продолжить чтение» **режим заучивания** (скрытый аят, проверка нажатием), озвучка отдельного аята с повтором до 10 раз, отметка «выучено» у сур кнопка «Поделиться аятом», поиск по тексту перевода и цель чтения (аятов в день, серия дней).
- **Арабский алфавит**: 28 букв, написание в начале/середине/конце слова, огласовки.
- **Установка на телефон и офлайн**: сайт можно добавить на главный экран; уже открытые суры и список сур читаются без интернета (аудио — только с интернетом).
- **Викторина**: столпы, пророки, Коран, имена Аллаhа; лучший результат по темам и «работа над ошибками».
- **Тасбих**, азкары, дуа.
- **99 имён Аллаhа** и пять столпов ислама.
- **Ссылки на каналы** в Telegram и TikTok.

Текст Корана, перевод, аудио и арабское написание имён Аллаhа подгружаются из интернета:
`api.alquran.cloud`, `cdn.islamic.network`, `api.aladhan.com`. Без интернета эти разделы не загрузятся.

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (например, `iman`).
2. Загрузите в него файлы `index.html`, `style.css`, `script.js`, `manifest.json`, `sw.js`, `README.md`, иконки `icon-192.png` и `icon-512.png`, а также папки `bot/` и `.github/` (для бота).
3. Откройте **Settings → Pages**.
4. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Через минуту сайт будет доступен по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

### Через Termux

```bash
pkg install git
git init
git add .
git commit -m "Исламский сайт"
git branch -M main
git remote add origin https://github.com/<ваш-ник>/<репозиторий>.git
git push -u origin main
```

Если вы уже загружали `config.js` или `supabase.sql` (версия с входом по почте), удалите их из репозитория: на сайте они больше не используются.

## Бот: аят дня в Telegram

1. В @BotFather создайте бота, скопируйте токен. Добавьте бота админом в канал с правом публикации.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   `TELEGRAM_BOT_TOKEN` (токен) и `TELEGRAM_CHAT_ID` (например `@quran_subtitl`).
3. Вкладка **Actions → Аят дня в Telegram → Run workflow** — пробная отправка. Дальше бот сам публикует каждый день в 10:00 по Бишкеку.
4. Проверка без отправки: `python3 bot/daily_ayah.py --dry-run`.

Бот идёт по Корану подряд, по одному аяту в день, начиная с 1 января 2026 года (аят №1), и после 6236-го начинает заново. Токен хранится только в секретах, в код его не вставляйте.

## Как менять содержимое

Тексты зикров и дуа находятся в начале `script.js` в массивах `DHIKR`, `DUAS`.

## Обновление сайта

Если вы изменили файлы сайта, откройте `sw.js` и увеличьте номер в `const VERSION = "iman-v14"` (например, `iman-v15`): так телефоны получат новую версию и удалят старый кэш.

## Защита страницы

В `index.html` включена политика CSP: страница общается только с `api.alquran.cloud`, `api.aladhan.com`, `cdn.islamic.network` и Google Fonts. Если подключите другой внешний сервис, добавьте его адрес в эту политику.
